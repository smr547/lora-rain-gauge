# Dashboard

## Purpose
This directory contains the User-facing presentation of rainfall information.

## Scope
Dashboard design, configuration, screenshots and documentation needed to reproduce the User interface belong here.

## User perspective
For Users, the dashboard is the visible product. It should make today's rainfall immediately apparent, provide useful recent and historical totals, support graphs, and indicate when data is stale.

## Does not belong here
Measurement acquisition, LoRa transport and SignalK adaptation belong elsewhere in the repository.

## Relationships
The dashboard consumes information made available through the site's data infrastructure after SignalK integration and historical storage.

## Status
Planned for Version 1 and subject to User review of the User Requirements Specification.
