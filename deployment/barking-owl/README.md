# Barking Owl Deployment

## Purpose
This directory records the actual Barking Owl installation of the LoRa Rain Gauge system.

## Scope
It may contain the device register, sanitised configuration, installation records, site notes, photographs, deployed software/firmware versions and acceptance-test results.

## Security
No credentials, passwords, API tokens, private keys or other secrets are to be committed. Site information should be limited to what is useful for engineering, operation and maintenance.

## Relationships
Generic product design belongs elsewhere in the repository. This directory records one particular deployment of that design.

## Status
Initial deployment planned. The first Version 1 rain-gauge node and base station will be recorded here when installed.
