# Deployments

## Purpose
This directory records real installations of the LoRa Rain Gauge product.

## Scope
Each deployment receives its own subdirectory containing the facts needed to identify, operate, verify and maintain that installed instance.

## Design versus deployment
Generic documentation says what the product is and how it is designed. Deployment documentation says what was actually installed at a particular site.

## Security
This is a public repository. Credentials, passwords, private keys, API tokens and other secrets must never be committed here. Sensitive site-security information should also be excluded.

## Relationships
Deployment records reference the generic hardware, firmware and documentation elsewhere in the repository.

## Status
Barking Owl is the initial deployment. Other sites, such as Reid, may be recorded here if systems are deployed there.
