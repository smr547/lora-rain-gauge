# Tools

## Purpose
This directory contains utilities that assist development, testing, deployment or maintenance but are not themselves part of the deployed product runtime.

## Scope
Diagnostic scripts, packet inspection utilities, provisioning helpers, data conversion tools and similar engineering aids may belong here.

## Does not belong here
Production firmware and services belong with their owning components.

## Relationships
Tools should support reproducible engineering and maintenance activities described elsewhere in the documentation.

## Status
Empty initially. Existing experimental utilities will be assessed during the asset inventory before being migrated.
