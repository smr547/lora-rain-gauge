# System Verification and Testing

## Purpose
This directory contains tests and evidence that exercise the assembled system across component boundaries.

## Scope
Integration tests, whole-system tests, field tests, acceptance procedures and reusable test fixtures belong here.

## Does not belong here
Tests tightly coupled to a single component may live with that component. Requirements traceability belongs in `docs/requirements/verification-matrix.md`.

## Relationships
Test evidence supports verification of system requirements and ultimately demonstrates that a deployment satisfies its acceptance criteria.

## Status
Initial. The Version 1 verification approach will be derived from the requirements.
