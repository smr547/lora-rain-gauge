# Operation and Maintenance

## Purpose
This directory contains information needed to use, maintain, diagnose and hand over an installed LoRa Rain Gauge system.

## Scope
User guidance, routine maintenance, troubleshooting, recovery procedures and maintainer handover material belong here.

## Does not belong here
Development build instructions belong in `docs/development/`. Site-specific installation facts belong in `deployment/<site>/`.

## Relationships
These documents describe how to operate and support systems built from this repository and recorded under `deployment/`.

## Status
Planned for Version 1. Operational documentation will be developed alongside the working appliances rather than reconstructed after deployment.
