# Development

## Purpose
This directory documents how developers build, program, test and work on the LoRa Rain Gauge system.

## Scope
Development environment setup, toolchains, programming procedures and development/test strategy belong here.

## Does not belong here
End-user operation belongs in `docs/operation/`. Product requirements and architecture belong elsewhere under `docs/`.

## Relationships
Development guidance supports work on the firmware, hardware, protocol, SignalK integration and dashboard components.

## Status
Initial. Existing experimental repositories will be inventoried before their useful knowledge is migrated or referenced.
