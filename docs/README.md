# Documentation

## Purpose
This directory contains the engineering documentation for the LoRa Rain Gauge product.

## Scope
Requirements, architecture, design decisions, operating information, development guidance and other material needed to understand, build, verify and maintain the system belong here.

## Does not belong here
Firmware source, hardware design files, deployment-specific configuration and executable tooling belong in their corresponding top-level directories.

## Relationships
Documentation in this directory describes the product implemented by `rain-gauge-node/`, `base-station/`, `protocol/`, `signalk/` and `dashboard/`.

## Status
Active. Documentation will grow with the implementation and is part of the maintained engineering product.
