# Architecture

## Purpose
This directory explains the structure of the LoRa Rain Gauge system and the responsibilities and relationships of its major components.

## Scope
System context, component responsibilities, interfaces, data flows, communications architecture and architectural diagrams belong here.

## Does not belong here
Individual design decisions with alternatives and rationale belong in `docs/adr/`. Detailed protocol definitions belong in `protocol/`. Requirements belong in `docs/requirements/`.

## Relationships
Architecture translates requirements into a coherent system structure. The implementation directories realise that structure.

## Status
Initial architecture is being established for Version 1 while deliberately allowing future sensor spokes to use the base station.
